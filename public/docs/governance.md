# MORE Governance

## Overview

MORE is an open standard maintained through transparent and documented evolution.

No single individual or organization owns or controls the standard.

---

## Principles

- Open participation is encouraged
- Implementations may vary
- Compatibility is defined by the published specification

---

## Versioning

Changes to the standard must:

1. Be documented
2. Be versioned
3. Preserve compatibility where possible

---

## Implementations

Multiple independent implementations may exist, including:

- authoring tools
- reader applications
- processing systems

No implementation is required to use the standard.a
